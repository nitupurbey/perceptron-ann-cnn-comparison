# CNN vs ANN for Image Classification

This project compares different neural network approaches for image classification, including:

- Perceptron
- Artificial Neural Network (ANN)
- Convolutional Neural Network (CNN)

The goal of this project is to analyze and demonstrate why CNN performs better than traditional neural network models for image-based datasets.

---

## Project Overview

Image classification is one of the most important tasks in deep learning and computer vision. In this project, multiple neural network architectures were implemented and compared based on their performance and accuracy.

The project includes:
- Data preprocessing
- Model building
- Training and evaluation
- Accuracy comparison
- Performance analysis

---

## Models Used

### 1. Perceptron
A basic single-layer neural network used for simple classification tasks.

### 2. Artificial Neural Network (ANN)
A fully connected neural network capable of learning more complex patterns than a perceptron.

### 3. Convolutional Neural Network (CNN)
A deep learning architecture specifically designed for image processing and feature extraction.

CNN achieved better performance because it:
- Captures spatial features
- Detects patterns automatically
- Reduces overfitting with parameter sharing
- Performs better on image datasets
